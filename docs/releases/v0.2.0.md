## Highlights

- Record microphone and system audio in the native macOS app and preserve the meeting before expensive AI work starts.
- Transcribe and diarize meetings locally, then turn the transcript into reviewable summaries, actions, decisions, risks and notes.
- Carry useful meeting outputs into Today and Project memory instead of leaving them inside isolated transcripts.
- Keep Local AI as the default trust boundary while making optional provider choices explicit rather than silent fallbacks.

## Compatibility

- Apple Silicon Mac.
- macOS 14 or later.
- Local inference uses the hardware and model runtimes bundled or configured by ClosedRoom; workload duration and memory use depend on the Mac and selected models.

## Installation

When this release is published, use the `ClosedRoom-v0.2.0-macos-arm64.dmg` asset from the GitHub Release. The normal downloadable release is published only from an exact artifact that has passed the repository's Developer ID, notarization, stapling and Gatekeeper checks.

macOS may ask for microphone and screen/system-audio capture permissions when ClosedRoom first uses those capabilities.

## Privacy

Meeting capture, transcription, speaker diarization and the default analysis path are designed around an on-device boundary. Optional cloud providers are explicit configuration choices; ClosedRoom must not silently send meeting content to a remote fallback.

## Known limitations

- ClosedRoom is still pre-1.0 software, so product and compatibility contracts can continue to evolve.
- The packaged app currently targets Apple Silicon rather than Intel Macs.
- macOS privacy permissions are part of native recording behavior and may need to be granted explicitly before microphone or system-audio capture can succeed.
