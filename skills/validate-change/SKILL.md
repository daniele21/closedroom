# Validate Change
Use the native selector to resolve outcome/owner -> risks -> gates -> profile. Prefer focused Python/frontend/native checks; shared API/persistence/privacy/lifecycle/packaging changes strengthen; selector/global/toolchain/unknown/release is FULL.

Classify failures before patching. Each failed repair needs a falsifiable hypothesis; **after two failed repairs with the same signature, change diagnostic strategy and gather new evidence before a third**. Never weaken a legitimate gate. Hosted macOS evidence never proves real TCC, physical audio or representative MLX/Metal behavior.

At integration run affected automated critical E2E; material UI/UX outcomes require `FULL_MEDIA`; target-Mac gaps are `DEFERRED_TO_RELEASE`. Report bounded source identity, risks/profile, gate reasons/status, evidence refs, gaps and next action without hiding FAIL/PENDING.
